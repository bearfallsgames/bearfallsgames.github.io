# bearfallsgames.github.io

The website for Bear Falls Games — a solo game studio.

[View it live](https://bearfallsgames.github.io)

## Structure

A single static page — `index.html`, styled by `assets/css/site.css`, with the
logo and game screenshots in `images/`. No build step, no dependencies.

Typefaces are Fraunces, DM Sans, and DM Mono, loaded from Google Fonts.
